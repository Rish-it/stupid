# Studio screens

Every screen at 1280px and 390px wide, in light and dark. Files are named `<screen>-<theme>-<width>.png`.

Captured from a dev build. Offline and welcome come from the app with no server behind it; the welcome screen gets a signed-out `/api/me`. The other screens use the dev-only `?fixtures=1` sample data, and their Sample data banner shows that none of it is real. In the Inbox capture a message is open with its reply box. In the Agents capture every agent has finished a run.
